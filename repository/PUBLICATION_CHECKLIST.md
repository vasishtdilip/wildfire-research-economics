# Deposit checklist

Prepared repository title: Data and code for Valuing staged research portfolios
for wildfire prevention. Creator: Vaishnavi Dilip, Independent Student Researcher,
Bangalore, India. Version: 1.0.0.

This package is prepared for deposit. It has not been published, and no DOI is
assigned or fabricated. The supplied metadata are a draft for a Zenodo dataset
record containing data, software and derived figures.

Before publication:

1. Confirm creator details and any ORCID, funding or contributors. Do not invent
   identifiers or treat the uploader as an additional author.
2. Confirm rights for the author's original contributions. The proposed choices
   are MIT for code and CC BY 4.0 for original documentation and figures. These
   are proposals only; no license grant is included yet. FEMA data remain under
   their own source terms, so the entire archive must not be blanket-relicensed.
3. Use the current consolidated archive as the deposited file. If manuscript
   files are included, confirm they correspond to the same equations and tables.
4. Obtain the DOI from the repository. Add it to the citation metadata and the
   manuscript data-availability statement. A reserved DOI is not evidence that
   the files are public; confirm publication and unauthenticated access.
5. Set the citation release date and repository publication date to the actual
   publication date. Recreate the SHA256 manifest after final metadata changes,
   then finalize the archive. Preserve the version-specific DOI in the manuscript citation.

The archive contains public source data and research code, without authentication
tokens, account files, private correspondence, or a license assertion over FEMA
materials.
